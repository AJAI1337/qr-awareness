# Phishing Simulation

Clearly labelled awareness training with fictional brands and fixed dummy values.

Open index.html for scenario selection, presentation.html for the briefing and qr.html for the audience exercise. Use a real published training URL for audience QR codes.

Static GitHub Pages does not run the local password-protected admin backend. This studio does not use the existing giveaway API.

The demo pages do not collect real credentials, payment data, visitor identities, IP addresses or user agents. Anonymous events are opt-in.
